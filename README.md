# 🚀 Trạm Điều Khiển AI Kép Tự Trị

Hệ thống AI kép gồm **Bộ não giao tiếp** và **Bộ não phân tích code**, hỗ trợ kiểm tra lỗi, viết và tối ưu code trực tiếp trên điện thoại, đồng bộ tự động lên GitHub.

## ⚠️ Lưu ý quan trọng
> Người dùng **tự điền mã API và Token** của riêng mình vào ô cấu hình bên trong ứng dụng. Thông tin này chỉ hiển thị trên thiết bị của bạn và không được chia sẻ với bất kỳ bên thứ ba nào.

1. Truy cập ứng dụng trên Streamlit Cloud
2. Điền thông tin GitHub Token và đường dẫn kho của bạn
3. Nhập yêu cầu cần hỗ trợ về code
4. Nhấn **"Phát lệnh"** và xem kết quả
